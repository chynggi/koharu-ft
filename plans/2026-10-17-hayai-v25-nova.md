# Hayai OCR v2.5 Nova 교체 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `hayai-ocr` 엔트리의 체크포인트를 v2에서 v2.5 Nova로 교체하고, 투영기·시각 RoPE·패치 예산·출력 정규화를 Nova에 맞춘다.

**Architecture:** 기존 `crates/koharu-ml/src/hayai_ocr/` 4파일 구조를 유지한다. `Projector`를 제자리에서 Nova `DSCProjector`(2×2 픽셀 언셔플 → LayerNorm → MLP → RMSNorm)로 바꾸고, `generate`는 압축 격자에서 2D RoPE를 돌리며 패딩 행 경로를 삭제한다. 출력은 `processor.rs`의 `normalize_text`(NFKC + CJK 내부 공백 제거)를 거친다. 변형 병존·별칭·분기는 만들지 않는다.

**Tech Stack:** Rust, `koharu-torch`(LibTorch 바인딩, `pixel_unshuffle`), `icu_normalizer` 2.3(NFKC), `tokenizers`.

**설계 문서:** `specs/2026-10-17-hayai-v25-nova-design.md`

**권위 구현:** `https://huggingface.co/JustANormalTinkerer/hayai-ocr-v2.5-nova/blob/2803d0dc005fa4396ab1e7c5a472d2c450a247f7/modeling_hayai.py`

## 계획 작성 시 업스트림과 대조한 사실

설계 문서 이후 `modeling_hayai.py`와 모델 카드(같은 commit)를 직접 읽어 확정한 값이다. 구현 중 다시 찾지 않는다.

| 항목 | 업스트림 | 로컬 대응 |
|---|---|---|
| `DSCProjector.norm` | `nn.LayerNorm(unshuffle_dim)` → eps **1e-5**(PyTorch 기본) | `nn::layer_norm(..., Default::default())` — `koharu-torch` 기본 eps도 1e-5 |
| `mlp[1]` | `nn.GELU()` → **exact(erf)** | `.gelu("none")` |
| `mlp[0]`, `mlp[2]` | `bias=False` | `nn::LinearConfig { bias: false, .. }` |
| `out_norm` | `RMSNorm(d_model)`, eps 1e-6 | 로컬 `RmsNorm`(`RMS_NORM_EPS = 1e-6`) |
| 채널 순서 | `gather_patches`가 `(L, r*r, d)`를 모은 뒤 `transpose(2, 3)` → `c * r*r + k`, `k = dy * r + dx` | `pixel_unshuffle(2)`의 `c * 4 + dy * 2 + dx`와 같다 |
| 홀수 변 | `sy = min(oy*r + dy, h - 1)` 인덱스 클램핑 | 마지막 행/열을 한 번 복제(배율 2이므로 부족분은 최대 1) |
| 단일 샘플 프리필 | `bucket = 1`이면 `m == h_out * w_out`, 시각 키 마스크 없음 | 기존 블록 인과 마스크 그대로 |
| 정규화 | `[\r\n\t]+ → ' '`, CJK `\s+` CJK 제거(1회 비중첩), `\s+ → ' '`, strip | D8대로 단일 스캔에서 모든 CJK 내부 공백 제거 |
| 패치 예산 표 | 256: CER 4.95% / EM 75.35% / 1.00x, 384: 3.65% / 79.15% / ~1.19x, 512: 3.10% / 80.68% / ~1.34x (JMangaBench_Mixed 3,286 crops, NFKC, T4) | `MAX_NUM_PATCHES` doc 주석 |

설계 문서와 다른 점은 하나다. 설계의 `Projector`에는 `d_vision: i64` 필드가 있지만, 채널 수는 입력 텐서에서 읽으므로 필드를 두지 않는다. 쓰이지 않는 필드는 죽은 상태다.

```rust
/// `H_out * W_out` tokens.
pub(super) fn decoder_vision_grid(patch_height: i64, patch_width: i64) -> (i64, i64) {
    (
        (patch_height + SPATIAL_DOWNSCALE - 1) / SPATIAL_DOWNSCALE,
        (patch_width + SPATIAL_DOWNSCALE - 1) / SPATIAL_DOWNSCALE,
    )
}
```

```rust
/// Cleans a decoded transcription like the upstream model card's
/// `normalize_text`: NFKC, whitespace runs collapsed to one space, spaces
/// between CJK characters removed, ends trimmed.
///
/// Deliberate divergence: upstream strips CJK-internal whitespace with one
/// non-overlapping `re.sub`, which leaves `"漢 字 漢"` as `"漢字 漢"`. That is a
/// side effect of the scan rather than intent, and translation input reads
/// better without the space, so this joins every CJK pair.
pub(crate) fn normalize_text(text: &str) -> String {
    let text = ComposingNormalizerBorrowed::new_nfkc().normalize(text);
    let mut normalized = String::with_capacity(text.len());
    for word in text.split_whitespace() {
        let joins_cjk = normalized
            .chars()
            .next_back()
            .zip(word.chars().next())
            .is_some_and(|(previous, next)| is_cjk(previous) && is_cjk(next));
        if !normalized.is_empty() && !joins_cjk {
            normalized.push(' ');
        }
        normalized.push_str(word);
    }
    normalized
}

/// Character class of the upstream `cjk_char` pattern: CJK unified ideographs,
/// hiragana and katakana, CJK extension A, and Hangul syllables.
fn is_cjk(character: char) -> bool {
    matches!(
        character,
        '\u{4E00}'..='\u{9FFF}'
            | '\u{3040}'..='\u{30FF}'
            | '\u{3400}'..='\u{4DBF}'
            | '\u{AC00}'..='\u{D7AF}'
    )
}
```

`split_whitespace`가 빈 입력·공백만 있는 입력에서 단어를 내지 않으므로 빈 문자열 분기는 따로 두지 않는다.

```rust
    use koharu_torch::Tensor;

    use super::unshuffle_patches;

    #[tokio::test]
    #[ignore = "requires the dynamically loaded LibTorch runtime"]
    async fn pixel_unshuffle_channel_order() -> anyhow::Result<()> {
        crate::init().await?;
        // A 3x3 grid of 2-channel patches followed by 3 padded rows the
        // projector must drop. Each value encodes (channel, row, column).
        let (height, width, channels) = (3i64, 3i64, 2i64);
        let mut values = Vec::new();
        for y in 0..height {
            for x in 0..width {
                for c in 0..channels {
                    values.push((c * 100 + y * 10 + x) as f32);
                }
            }
        }
        values.extend(std::iter::repeat_n(-1.0f32, 3 * channels as usize));
        let features = Tensor::from_slice(&values).view([1, height * width + 3, channels]);

        let (tokens, height_out, width_out) = unshuffle_patches(&features, height, width);
        assert_eq!((height_out, width_out), (2, 2));
        assert_eq!(tokens.size(), vec![1, 4, channels * 4]);

        // Upstream `gather_patches`: channel `c * 4 + dy * 2 + dx`, with odd
        // sides clamped to the last row/column.
        let mut expected = Vec::new();
        for oy in 0..height_out {
            for ox in 0..width_out {
                for c in 0..channels {
                    for dy in 0..2 {
                        for dx in 0..2 {
                            let y = (oy * 2 + dy).min(height - 1);
                            let x = (ox * 2 + dx).min(width - 1);
                            expected.push((c * 100 + y * 10 + x) as f32);
                        }
                    }
                }
            }
        }
        assert_eq!(Vec::<f32>::try_from(&tokens.reshape([-1]))?, expected);
        Ok(())
    }
```

- [ ] **Step 4: `Projector`를 `DSCProjector`로 교체한다**

기존 `Projector` 정의와 `impl Projector` 전체(`#[derive(Debug)] struct Projector { linear1 ... }`부터 `forward`의 닫는 괄호까지)를 다음으로 바꾼다.

```rust
/// Nova `DSCProjector`: merges every 2x2 block of valid patches into one
/// token, then LayerNorm -> MLP -> RMSNorm.
#[derive(Debug)]
struct Projector {
    norm: nn::LayerNorm,
    mlp1: nn::Linear,
    mlp2: nn::Linear,
    out_norm: RmsNorm,
}

impl Projector {
    fn new(path: &nn::Path<'_>, d_vision: i64, d_model: i64) -> Self {
        let unshuffled_dim = d_vision * SPATIAL_DOWNSCALE * SPATIAL_DOWNSCALE;
        let no_bias = nn::LinearConfig {
            bias: false,
            ..Default::default()
        };
        Self {
            // Upstream `nn.LayerNorm(unshuffle_dim)` keeps PyTorch's 1e-5 eps.
            norm: nn::layer_norm(path / "norm", vec![unshuffled_dim], Default::default()),
            mlp1: nn::linear(path / "mlp" / 0, unshuffled_dim, d_model, no_bias),
            mlp2: nn::linear(path / "mlp" / 2, d_model, d_model, no_bias),
            out_norm: RmsNorm::new(&(path / "out_norm"), d_model),
        }
    }

    /// Returns the visual prefix and its compressed `(height, width)` grid.
    fn forward(
        &self,
        visual_features: &Tensor,
        patch_height: i64,
        patch_width: i64,
    ) -> (Tensor, i64, i64) {
        let (tokens, height_out, width_out) =
            unshuffle_patches(visual_features, patch_height, patch_width);
        // Upstream `nn.GELU()` is the exact erf form.
        let hidden = self
            .mlp1
            .forward(&self.norm.forward(&tokens))
            .gelu("none");
        (
            self.out_norm.forward(&self.mlp2.forward(&hidden)),
            height_out,
            width_out,
        )
    }
}

/// Gathers each 2x2 block of this image's valid patches into one token
/// (upstream `DSCProjector.gather_patches`). With a downscale of 2 an odd side
/// lacks exactly one row or column, which is replicated: upstream clamps the
/// gather index to the last row/column. The channel layout
/// `c * 4 + dy * 2 + dx` equals upstream's `(L, rr, d) -> (L, d, rr)` transpose,
/// so the checkpoint's LayerNorm and first MLP columns load unchanged.
fn unshuffle_patches(
    visual_features: &Tensor,
    patch_height: i64,
    patch_width: i64,
) -> (Tensor, i64, i64) {
    let channels = visual_features.size()[2];
    let (height_out, width_out) = decoder_vision_grid(patch_height, patch_width);
    let mut grid = visual_features
        .narrow(1, 0, patch_height * patch_width)
        .reshape([1, patch_height, patch_width, channels])
        .permute([0, 3, 1, 2]);
    if height_out * SPATIAL_DOWNSCALE > patch_height {
        let last_row = grid.narrow(2, patch_height - 1, 1);
        grid = Tensor::cat(&[grid, last_row], 2);
    }
    if width_out * SPATIAL_DOWNSCALE > patch_width {
        let last_column = grid.narrow(3, patch_width - 1, 1);
        grid = Tensor::cat(&[grid, last_column], 3);
    }
    let tokens = grid
        .contiguous()
        .pixel_unshuffle(SPATIAL_DOWNSCALE)
        .permute([0, 2, 3, 1])
        .reshape([
            1,
```

```rust
                    padding.unsqueeze(0),

            )
```
