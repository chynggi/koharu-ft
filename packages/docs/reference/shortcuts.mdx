Tool and editing shortcuts apply while a project is open and an input, textarea, or editable text region is not focused.

## Tools

| Tool                | Key                     |
| ------------------- | ----------------------- |
| Select              | `V`                     |
| Direct Selection    | `A`                     |
| Rectangular Marquee | `M`                     |
| Lasso               | `L`                     |
| Text                | `T`                     |
| Rectangle, Ellipse  | `U`, again for the next |
| Brush               | `B`                     |
| Eraser              | `E`                     |
| Paint Bucket        | `G`                     |
| Color picker        | `I`                     |
| Remove              | `J`                     |
| Pan                 | `H`                     |

Each key is Photoshop's for the same tool.

## Navigation

| Action                | Gesture                                                               |
| --------------------- | --------------------------------------------------------------------- |
| Pan temporarily       | Hold `Space` or the middle button and drag                            |
| Pan                   | Scroll; `Shift` + scroll pans horizontally                            |
| Zoom at the pointer   | `Ctrl` or `Command` + scroll, or pinch                                |
| Change brush size     | `Alt` + scroll or `Ctrl` + `Alt` + drag with Brush, Eraser, or Remove |
| Previous or next page | `Left Arrow` or `Right Arrow` with no layer selected                  |
| Clear the selection   | `Escape`                                                              |
| Fit the active page   | `Ctrl+0` or `Command+0`                                               |

Releasing `Space` returns to the tool you were using.

## Editing

| Action                                                              | Windows / Linux         | macOS                   |
| ------------------------------------------------------------------- | ----------------------- | ----------------------- |
| Undo                                                                | `Ctrl+Z`                | `Command+Z`             |
| Redo                                                                | `Ctrl+Shift+Z`          | `Command+Shift+Z`       |
| Select all layers on the page                                       | `Ctrl+A`                | `Command+A`             |
| Deselect the area marked with Rectangular Marquee or Lasso          | `Ctrl+D`                | `Command+D`             |
| Delete selected layers, or the anchors picked with Direct Selection | `Delete` or `Backspace` | `Delete` or `Backspace` |
| Commit text typed on the canvas                                     | `Ctrl+Enter`            | `Command+Enter`         |
| Move selected layers 1 pixel, or 10 with `Shift`, with Select       | Arrow keys              | Arrow keys              |
| Duplicate selected layers                                           | `Ctrl+J`                | `Command+J`             |
| Copy selected layers                                                | `Ctrl+C`                | `Command+C`             |
| Paste copied layers onto the shown page                             | `Ctrl+V`                | `Command+V`             |

Shortcuts affect the desktop interface, not the exported page.
