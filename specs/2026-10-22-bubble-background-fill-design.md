# 말풍선 배경 채우기 판정 강건화 설계

작성일: 2026-10-22

## 배경

인페인팅 단계는 모델을 돌리기 전에 탐지된 말풍선(`BubbleRegion`)마다 배경이
균일한지 판정하고, 균일하면 text-mask 픽셀을 중앙값 색으로 채운 뒤 그 픽셀을
모델 마스크에서 뺀다(`crates/koharu-pipeline/src/stages/inpainting.rs`의
`fill_uniform_regions` / `uniform_region_color`). BallonsTranslator의 같은
최적화를 따른 것이다.

판정은 폴리곤 내부·테두리 3px 바깥·마스크 밖 픽셀을 샘플로 모아 채널별
**표준편차**가 7~10 미만인지 본다. 표준편차는 소수의 이상치에 약해서, 흑백
만화의 흰 말풍선에 검은 픽셀이 2%만 섞여도 값이 30을 넘는다.

## 관찰 (`03.webp`, 2040×2880)

`koharu_layout_rfdetr_seg_2xl`로 탐지하고 판정을 Python으로 재현했다. 말풍선
마스크는 주석 이미지 오버레이에서, text-mask는 텍스트 bbox를 같은 반경(17px)으로
팽창·닫힘해 근사했으므로 앱과 픽셀 단위로 같지는 않다.

| 말풍선 | 중앙값 | 최대 표준편차 | 중앙값 ±24 비율 | 현재 판정 |
|---|---|---|---|---|
| 검은 박스 6개 | 0 | 0.1~2.1 | 99~100% | 채움 |
| 「ふふ…生徒と」 검은 박스 | 0 | 42.7 | 94.8% | 모델 |
| 흰 말풍선 5개 | 255 | 15.9~47.7 | 95.6~99.3% | 모델 |
| 「何を…期待して」 세로 그라데이션 박스 | 149 | 103.9 | 2.7% | 모델 |

- 불투명인데 모델로 간 6개의 이상치 픽셀은 전부 말풍선 외곽선·꼬리 접합부에
  있었다(테두리 8px 이내 43~100%, 나머지도 20px 이내). 텍스트 잔여 잉크는 없었다.
- 그라데이션 박스는 text-mask가 박스 면적의 약 73%를 덮는다. FLUX 계열 모델은
  남은 얇은 띠만 보고 빈 칸을 생성하다가 관계없는 그림(성)을 그렸다.
- 같은 박스를 행별 중앙값 프로파일로 예측하면 샘플의 97.0%가 ±8 이내로 맞고,
  채운 결과도 원래 그라데이션과 구분되지 않았다. 열 프로파일은 39.6%, 3차 이하
  다항식 곡면은 최대 88%였다.

## 목표

- 외곽선 이상치가 섞인 불투명 말풍선을 모델 없이 채운다.
- 축 방향 그라데이션 말풍선·박스를 모델 없이 채운다.
- 배경이 비치는 말풍선과 질감 배경은 지금처럼 인페인팅 모델로 보낸다.

## 비목표

- Vision 모델 분류. 이번 실패는 분류가 아니라 판정 통계의 문제였다. 실제 오분류
  사례가 나오면 별도로 검토한다.
- FLUX 업샘플러 캡션·프롬프트 조정. 이 변경 뒤에도 질감 배경에서 환각이 남으면
  별도로 다룬다.
- 새 설정 항목, 모델, 스키마, UI.

## 설계

변경은 `inpainting.rs`의 배경 판정과 채우기에 한정한다. 샘플 추출 규칙(폴리곤
내부, `FLAT_FILL_EDGE_MARGIN` 3px, `pending_mask` 밖), 최소 샘플 수
`UNIFORM_BACKGROUND_MIN_PIXELS`(16), 채우는 대상(폴리곤 안의 `pending_mask`
∧ `text_mask` 픽셀), 채운 픽셀을 `pending_mask`에서 지우는 동작은 그대로 둔다.

### 배경 모델

`uniform_region_color`를 영역의 배경 모델을 돌려주는 판정으로 바꾼다.

```rust
enum RegionBackground {
    Flat(Rgb<u8>),
    // 영역 bounds의 top부터 행마다 한 색
    Rows(Vec<Rgb<u8>>),
    // 영역 bounds의 left부터 열마다 한 색
    Columns(Vec<Rgb<u8>>),
}
```

- **Flat**: 샘플 전체의 채널별 중앙값. 지금과 같다.
- **Rows**: 샘플이 있는 행마다 채널별 중앙값을 낸 뒤, 위아래 ±4행 창 안의
  샘플을 합쳐 중앙값을 다시 구해 평활화한다. 샘플이 없는 행은 위아래에서 가장
  가까운 샘플 행 값을 선형 보간한다.
- **Columns**: Rows와 같은 방식을 열 단위로 적용한다.

창으로 평활화하는 이유는 샘플이 몇 개뿐인 행에서 중앙값이 자기 샘플에 과적합돼
질감 배경이 통과하는 것을 막기 위해서다.

### 판정

각 모델로 모든 샘플의 배경을 예측하고, 세 채널 차이의 최댓값이
`BACKGROUND_INLIER_TOLERANCE`(12) 이하인 샘플을 inlier로 센다. inlier 비율이
`BACKGROUND_INLIER_RATIO`(0.90) 이상이면 그 모델을 받아들인다.

1. Flat이 기준을 넘으면 Flat.
2. 아니면 Rows와 Columns 중 inlier 비율이 높은 쪽이 기준을 넘으면 그 모델
   (같으면 Rows).
3. 아니면 `None` — 그 말풍선은 모델로 보낸다.

Rows/Columns는 외삽하지 않는다. 채울 픽셀의 행(열)이 샘플이 있는 첫 행(열)과 마지막
행(열) 사이를 벗어나면 그 모델은 기각한다.

관찰 수치 기준으로 불투명 말풍선의 Flat inlier 비율은 94.8% 이상, 그라데이션
박스의 Flat은 3% 미만, Rows는 97%다. 0.90은 양쪽에 여유를 둔 값이다.

### 채우기

`fill_uniform_regions`는 받아들인 모델로 각 대상 픽셀의 색을 정한다. Flat은 한 색,
Rows는 `colors[y - top]`, Columns는 `colors[x - left]`다.

### 정리

`standard_deviation`과 channel spread에 따른 7/10 문턱 분기는 삭제한다.
`uniform_region_color`는 색 하나가 아니라 배경 모델을 돌려주므로
`region_background`로 바꾼다. `fill_uniform_regions`를 비롯한 다른 이름은 그대로
둔다. 상단의
BallonsTranslator 주석은 출처로 남기고, 강건 판정과 프로파일 모델이 의도적인
차이라는 점을 한 줄 덧붙인다.

## 테스트

`inpainting.rs`의 기존 테스트 모듈에 단위 테스트를 추가한다.

- 흰 말풍선 샘플의 약 3%에 검은 외곽선 픽셀을 섞은 경우 → Flat 흰색으로 채워지고
  해당 픽셀이 `pending_mask`에서 빠진다. 이번 버그의 회귀 경계다.
- 위에서 아래로 어두워지는 세로 그라데이션 박스 → Rows로 채워지고, 채운 픽셀과
  원래 그라데이션의 차이가 허용치 이내다.
- 체커보드 스크린톤 배경 → `None`, 마스크가 그대로 남아 모델로 간다.
- 채울 행이 샘플 행 범위 밖에 있는 그라데이션 → Rows 기각.

기존 `uniform_mask_background_is_filled_without_inference`,
`uniform_bubbles_are_filled_independently_inside_one_textured_tile`은 그대로 통과해야
한다.

검증은 debug 프로필로 `cargo test -p koharu-pipeline` 중 인페인팅 테스트만 돌린다.
`03.webp`를 앱에서 다시 처리해 6개 말풍선과 그라데이션 박스가 모델 없이 채워지는지는
사용자가 확인한다.

## 남은 위험

- 이 페이지에는 반투명 말풍선이 없어서, 배경이 비치는 말풍선이 0.90 기준을 넘는지는
  관찰하지 못했다. 매끈한 배경(피부, 하늘) 위의 반투명 말풍선은 Rows/Columns로
  채워질 수 있는데, 그 경우 결과도 배경과 대체로 이어진다.
- 대각선·방사형 그라데이션은 Rows/Columns로 맞지 않아 지금처럼 모델로 간다.
